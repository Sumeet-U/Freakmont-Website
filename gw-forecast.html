How this reads

Guild War is a rank tournament: everyone in the 5-guild bracket is pooled into one ranking by real Guild War damage, and each participant earns the fixed points for their rank (1st = 1,000,000, 2nd = 900,000, … it's the position that pays, not the damage itself). Freakmont's own numbers come from the daily scrape; opponent guilds are fetched fresh from their public mapleidle.gg guild page the same way. This is a projection from whatever Guild War score is currently on file for each player — a fresh run, an off week, or a new member with no recorded run yet will all shift a real result away from this snapshot. Update data/freakmont/gw-opponents.json whenever the matchup changes to refresh who's compared against whom.
